# 🚀 دليل رفع وتشغيل منصة "تَنافُسْ" على Render كـ Web Service وربط بوت تليجرام

تم إعداد المنصة وتطويرها لتكون **خدمة ويب متكاملة (Node.js/Express + React Vite)** جاهزة بنسبة 100% للرفع المباشر على منصة **Render** مجاناً، مع دعم كامل للـ Webhook وبوت تليجرام والذكاء الاصطناعي (Gemini).

---

## 📌 الخطوات السريعة للرفع على Render (Web Service):

### الخطوة 1: رفع الكود على GitHub
1. قم برفع المشروع على حسابك في GitHub (إذا لم يكن مرفوعاً بالفعل).
2. تأكد من وجود ملفي `render.yaml` و `server.ts` في المستودع.

### الخطوة 2: إنشاء الخدمة في Render
1. ادخل إلى موقع [Render.com](https://render.com) وسجّل الدخول.
2. اضغط على زر **New +** ثم اختر **Web Service**.
3. اختر مستودع الـ GitHub الخاص بك (Repository).
4. املأ الإعدادات التالية (إذا لم يقرأها تلقائياً من `render.yaml`):
   - **Name:** `tanafas-platform` (أو أي اسم تفضله)
   - **Environment:** `Node`
   - **Region:** Frankfurt (أو أي منطقة قريبة)
   - **Branch:** `main`
   - **Build Command:** `npm run build`
   - **Start Command:** `npm run start`
   - **Instance Type:** `Free`

### الخطوة 3: إضافة متغيرات البيئة (Environment Variables)
في صفحة الإعدادات (Environment) في Render، أضف المتغيرات التالية:
- `NODE_ENV` = `production`
- `GEMINI_API_KEY` = *(مفتاح Gemini الخاص بك لإنشاء الأسئلة بالذكاء الاصطناعي)*
- `TELEGRAM_BOT_TOKEN` = *(رمز توكن البوت من BotFather - اختياري ويمكن ضبطه لاحقاً من لوحة تحكم الإدارة)*

ثم اضغط **Deploy Web Service**.

---

## 🤖 خطوات تفعيل بوت تليجرام والنشر في الجروبات

### 1. إنشاء بوت جديد:
1. افتح تليجرام وابحث عن `@BotFather`.
2. أرسل الأمر `/newbot`.
3. اختر اسماً للبوت (مثل: `منصة تنافس للسباقات`) ثم اسم مستخدم ينتهي بـ `bot` (مثل: `TanafasQuizBot`).
4. سيعطيك BotFather رمز التوكن الخاص بالبوت `HTTP API Token` (شكله: `123456789:ABCdefGhI...`).

### 2. ربط البوت بالمنصة:
1. افتح لوحة تحكم المشرف العام في منصتك (`/admin` أو من القائمة العليا).
2. توجّه إلى تبويب **"بوت تليجرام ونشر المسابقات"**.
3. الصق رمز البوت واضغط **"فحص والاتصال بالبوت"**.
4. ستظهر معلومات البوت وصورته واسمه فورياً.

### 3. تفعيل الـ Webhook (لاستقبال ردود الطلاب وأوامرهم):
- في نفس التبويب، أدخل رابط موقعك على Render:
  `https://your-app-name.onrender.com`
- اضغط زر **"حفظ وتفعيل Webhook البوت تلقائياً"**.

### 4. إضافة البوت للجروبات وتفعيل البث:
1. أضف البوت كعضو أو مشرف في جروب تليجرام المستهدف.
2. أرسل في الجروب `/id` أو أضف معرف الجروب (Chat ID مثل `-1001234567890`) في قائمة الجروبات المستهدفة في لوحة التحكم.
3. فعّل خيار **"النشر التلقائي للمسابقات الجديدة"** أو **"نشر النتائج ولوحة الشرف"**.
4. يمكنك أيضاً الضغط على زر **"بث بتليجرام"** أو **"بث النتائج"** بنقرة واحدة من بطاقة أي مسابقة في لوحة التحكم!

## 🎯 أوامر البوت المتاحة للطلاب في تليجرام:
- `/start` : الترحيب بالطالب وعرض أزرار سريعة للانتقال للمسابقات أو الموقع.
- `/competitions` : استعراض جميع المسابقات العامة والنشطة مع أزرار المشاركة المباشرة.
- `/id` : معرفة رقم المحادثة أو الجروب الحالي لربطه باللوحة.
- `/help` : دليل استخدام البوت والمنصة.

## 🔒 خيار عام أو خاص للمسابقات:
- عند إنشاء أي مسابقة (سواء من مسابقات المدير أو مسابقات المعلمين):
  - **عامة (Public) 🌐:** تظهر في الواجهة الرئيسية للمنصة للجميع، ويستطيع البوت عرضها وإرسالها للجروبات.
  - **خاصة (Private) 🔒:** تكون مخفية تماماً من الصفحة الرئيسية، ولا يعرضها البوت للعامة، وتتاح فقط للطلاب الذين يمتلكون الرابط المباشر للمسابقة.
